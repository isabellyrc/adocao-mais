# 🐾 Adote Aqui

Este projeto é um sistema de adoção de animais que conta com uma interface de linha de comando (Terminal) e protótipos de interface Web (HTML/CSS/JS).

## 🚀 Funcionalidades da Interface (Terminal)
- Cadastro e consulta de **Animais**.
- Gerenciamento de **Tarefas**.
- Sistema de **Sugestões** e **Matching**.

## 💻 Como executar o Menu do Terminal
1. Certifique-se de ter o Python instalado na sua máquina.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:
   ```bash
   python interface.py
   ```
